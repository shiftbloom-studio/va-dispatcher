# Support

VA Dispatch is maintained as an open-source project. Support is provided on a
best-effort basis and does not carry a service-level agreement.

Before asking for help:

1. Read the [README](README.md) and relevant documentation in `docs/`.
2. Search existing issues for the same question or error.
3. Confirm the problem still occurs on the latest supported revision.

Use the GitHub support-question issue form and include the component, revision,
environment, expected result, actual result, and a minimal reproduction. Redact
credentials and personal or operational data from logs and screenshots.

- Use the bug form for reproducible defects.
- Use the feature form for product proposals.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never report them in a
  public issue.

Questions about third-party services such as Clerk, Neon, Vercel, or Hoppies may
ultimately need to be handled by that provider's support channel.
